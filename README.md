# さんすう れんしゅう

年長さんと小学2年生向けの算数練習アプリ。タブレットのブラウザで動くPWA（ホーム画面に追加するとアプリのように全画面で起動する）。

## いまできること（MVP）

「タイル算」（1＝小さな正方形、10＝10のぼう、100＝板）で、10のまとまりと面積を目で見て理解する。

| 単元 | 子供がやること | 対象 |
|---|---|---|
| たしざん ①〜③ | 赤と青のタイルを「がっちゃん」で合わせる。10こそろうと1本の「10のぼう」になる（繰り上がり） | 年長 |
| ひきざん ①② | タイルをタップして取る。10のぼうから取るとぼうがばらばらになる（繰り下がり） | 年長〜1年 |
| おおきい かずの たしざん | 2けた①（一の位だけ繰り上がる）／2けた②（答えが100をこえる）／3けた。右に筆算、左に位ごとのタイル（一＝小さな正方形、十＝10のぼう、百＝100の板）。一の位から順に「7 + 5」「1 + 4 + 3」と答えると、10こそろったタイルが薄くなり、となりの位に黄色いぼう・板が届く | 2年 |
| かけざん（くく） | ①横の目盛りをなぞって「1つぶんの数」を選ぶ → ②縦の目盛りで「いくつぶん」を選ぶ → ③できた長方形の面積を答える | 2年 |
| 2けたのかけざん | 目盛りで 23 と 14 を選ぶと、長方形が 20×10／3×10／20×4／3×4 の部屋に分かれる。部屋ごとに答えてから合計する（面積図） | 2年〜 |
| くく タイムアタック | 150秒で何問正解できるか。「じゅんばん」（1×1→9×9、終わったら1×1へ戻る）と「ランダム」。答えの桁数まで打つと自動で答え合わせ。2回まちがえると答えを見せて次へ（正解に数えない）。結果にモード別ランキング上位5回 | 2年 |
| タイルで あそぶ | 問題なし。盤をなぞって自由に長方形を作り、式と部屋ごとの計算を見る（九九表 10×10、2けた 30×30） | 全員 |

- 1セット10問（だんごとの練習は9問）。テンキーで答える
- 「かぞえる」ボタン：たし算・ひき算はタイルを1こずつ番号をつけて光らせる。九九は1列ずつ光り、2 → 4 → 6… と足していく様子を見せる
- 「えを かくす」ボタン（たし算・ひき算）：絵なしで答える練習（暗算への移行）
- 目盛りを違う数で選んだときは、やり直しになる（記録上のまちがいにはしない）
- 答えを1回目に間違えたらやり直し、2回目は答えを見せる。どちらも記録上は「まちがい」になる
- 結果画面：正解数・かかった時間、間違えた問題だけをもう一度解く
- 記録はタブレットの中（localStorage）にだけ保存する。ホームに各レベルの最高記録が出る

## こどもごとの記録とポイント

- 開くたびに「だれが やる？」で子供を選ぶ。記録・最高記録・ポイントは子供ごとに分かれる（タイムアタックのランキングだけは全員いっしょで、名前つき）
- 名前は「✏️ なまえ」で変える。「＋ こどもを ふやす」で増やせる
- ポイントのルール：難しい問題ほど多くもらえる（`rewards.js` の `pointRuleFor()` と `POINT_RULES` で変更できる）。ホームの各カードに「1もん ○pt・ぜんぶ せいかい +○」と表示

| 問題 | 1問正解（1回目で） | 全問正解ボーナス |
|---|---|---|
| たしざん・ひきざん、九九 1〜5のだん | 1pt | +2 |
| 九九 6〜9のだん・くく ばらばら | 1pt | +5 |
| 大きい数のたしざん・2けたのかけざん | 2pt | +5 |
| 受験の土台（1年・2年前半・2年後半） | 2pt | +10 |
| 受験の土台 チャレンジ | 3pt | +10 |
| タイムアタック じゅんばん | 1pt | なし |
| タイムアタック ランダム | 正解数 − まちがい数（0未満にならない） | なし |

| そのほか | ポイント |
|---|---|
| その日に3セット（毎日の目標） | +20 |
| 目標を連続で達成（2日目から） | 連続日数 × 2（最大 +14） |

- 勉強のポイントは1日250ptまで。目標と連続のボーナスは上限の外
- 「まちがえた問題をもう一度」は正解ポイントのみ（全問正解ボーナス・目標の回数には数えない）。タイムアタックも1セット。途中でやめたセットはポイントなし
- ポイントは子供ごとの「さいふ」（`mathapp.v1.wallet.<子供のid>`）にたまる。むしのお店は `spendPoints()` でここから使う

## むしの おへや（ポイントで むしを そだてる）

ホームの「🐜 むしの おへや」から入る。子供ごとに別々。はじめて入るとアリ1匹とゼリー3こがもらえる。

- **3D**：しいくケースの中をむしが歩き回る（まるたは乗りこえる）。土は9cmあり、ようちゅう・さなぎ・冬眠中のクワガタは土の中のガラスぎわにいて、横から観察できる。ドラッグで回す、ピンチで拡大、タップでむしを選ぶ（ダンゴムシは丸くなる）。three.js はCDN（jsDelivr の +esm。import map を使わないので古い iPad でも読める）から読み込み、一度開けばオフラインでも動く。3D が使えないブラウザでは自動で「かんたん表示」（2D、`flatroom.js`）になり、同じように育てられる。`?flat=1` をURLにつけると2Dを試せる
- **えさ**：1匹1日1こ（さなぎ・冬眠中は食べない）。むしが増えるほどポイントがかかる
- **はらぺこ**：**5日えさをもらえないと死ぬ**（ようちゅうも）。2日目から「⚠️ よわっている！ あと◯にち」と出て、ケースのタブも赤くなる
- **そだつ**：ようちゅう → さなぎ → せいちゅう。**勉強した日**（1セット以上終わった日）の数で進む
- **おおきさ**：ようちゅうの間にあげたえさで決まる。マットだけだと小さめ、きんしエキス・ロイヤルゼリーをあげるほど大きくなる（`sizeFromGrowth`）
- **じゅみょう**（せいちゅうになってから）：カブトムシ 3か月、クワガタ 2年、カナブン 2か月、アリ 1年、ダンゴムシ 2年
- **冬眠**：クワガタのせいちゅうは 12月15日〜翌年6月1日まで土にもぐって眠る（えさ不要、はらぺこにならない）
- **おきもの**：とまりぎ（60）・すべりだい（150）・ブランコ（200）・きのこのおうち（250）。ケースごとに置ける数が決まっている（はじめの・小 2、中 3、大 4）。せいちゅうが遊びに行く（のぼる・すべる・ゆれる・かくれる）
- **ずかん**：かったことのある種類・最大サイズ・かった数・育てた数・説明。くるくる回る3Dモデル付き（こうちゅうは ようちゅう／さなぎ／せいちゅう を切りかえられる）。死んだむしは「おもいで」に残る
- 死んだり育ったりは、おへやを開いたときにまとめて判定してお知らせする（アプリを開かない日も、日付でさかのぼって判定する）

## さかなの おへや（ポイントで さかなを そだてる）

ホームの「🐟 さかなの おへや」から。子供ごとに別々（`mathapp.v1.fish.<id>`）。はじめて開くと、せんめんき・メダカ2ひき（メダカとヒメダカ）・えさ6こ・カルキぬき2こがもらえる。

- **えさ**：1ぴき1日1こ（アロワナはアロワナのえさ）。5日もらえないと死んでしまう
- **水**：毎日よごれる。魚が多いほど早く、ろかフィルター（約1/3）や水草で遅くなる。「みずかえ」でカルキぬき（水質調整剤）を使うと、きれいになる（1日1回）。よごれきったまま3日たつと死んでしまう。3Dでも水がにごって見える
- **育つ**：買ってから「勉強した日」の数で大きくなる（メダカ10日、金魚30日、アロワナ90日でおとな）
- **3D**：体をくねらせて泳ぎ、メダカ・グッピー・ネオンテトラは群れで泳ぐ。えさをあげると水面に集まって食べる。エアポンプの泡、フィルターの水の流れ、ヒーターのランプ、水底のゆらゆらした光も動く。3Dが使えないときは2Dの「かんたん表示」

| 水そう | pt | 水量 | 1種類だけ飼うときの目安 | できること |
|---|---|---|---|---|
| せんめんき | 最初から | 約6L | メダカ4 | メダカだけ |
| きんぎょばち | 250 | 約7L | メダカ5・金魚1（わきん・ピンポンパール・でめきん） | 水草入り |
| 30cm水そう | 500 | 12L | メダカ10・金魚2・リュウキン2 | エアポンプ・ろかフィルターが必要（ここから上すべて） |
| 60cm水そう | 1200 | 61L | メダカ30・金魚6・グッピー50・ベタ1 | ちがう魚をいっしょに飼える |
| 90cm水そう | 2000 | 166L | メダカ80・金魚8・グッピー/ネオンテトラ100・エンゼル8 | ヒーターで熱帯魚 |
| 180cm水そう | 4000 | 609L | 金魚30・エンゼル30・アロワナ1 など | アロワナ |

- 目安は飼育の解説サイトの数字（メダカは水2Lに1〜2匹、小型魚は30cmで6匹・60cmで50匹・90cmで100匹以上、エンゼルは90cmで7〜10匹、金魚は30cmで1〜2匹・90cmで7〜8匹、アロワナは180cm以上）。水そうの大きさは東京アクアガーデン「水槽サイズの選び方」の規格サイズ
- ちがう魚をいっしょに飼うときは「1匹 ＝ 1/目安」を足して1まで（こみぐあい）
- アロワナはほかの魚を食べてしまうので、からっぽの水そうで1匹で飼う
- タブレットでなめらかに動くように、1つの水そうに入れられるのは50匹まで
- 見た目：水は深いほど青く、奥ほどかすむ。水底にゆれる光、光のすじ、ただよう小さなつぶ、水面とガラスのさかいめの光る線。底は田砂（大磯砂のような小石まじり）で、ガラスごしに砂の断面が見える。せんめんきは赤玉土、きんぎょばちは白い砂とガラスのじゃり
器具：エアポンプ 100、ろかフィルター 150、ヒーター 200（水そうごと）。えさ 2、アロワナのえさ 10、カルキぬき 5（30cmまで1こ・60cm 2こ・90cm 4こ・180cm 8こを使う）。
おきもの：みずくさ・いし・かいがら・りゅうぼく・おしろ・ちんぼつせん。値段などは `fish.js` の `TANKS`・`FISH`・`EQUIPS`・`FISH_FOODS` で変えられる。

### Blender で作ったモデル

メダカ・ヒメダカと金魚のなかま（わきん・リュウキン・ピンポンパール・でめきん・たんちょうらんちゅう）は Blender で作ったモデル（`models/*.glb`）を使う。金魚の形と色は AQUALASSIC「超金魚大図鑑」の写真を参考にした。さらさ模様の金魚は模様のちがうモデルを2〜3種類作り、1匹ずつ選ぶ。ほかの魚と、モデルが読み込めないときはプログラムで作った形（`fish3d.js` の `LOOK`）になる。

- 作り方：`blender/medaka.py`・`blender/goldfish.py`（形・色・もようを Python で作って書き出す。金魚は `SPECS` で種類ごとの形を決める）
- 作り直す：math-app フォルダで `node blender/build.mjs`（Blender で書き出し → gltf-transform で軽くする。1体 70KB くらい）。`node blender/build.mjs wakin` のように名前の一部を書くと、その種類だけ作る
- 決まり：長さ1、はなさき z=+0.5、せなかが上。メッシュ名は `body`・`fins`（泳ぐときにくねる）と `iris`・`pupil`・`wen`（肉瘤）・`stalk`（出目の根もと）。`fins` の uv.y はひれのねもと0 → 先1
- 新しい魚を足すとき：`blender/` に作り方を足し、`build.mjs` の `MODELS` と `fish3d.js` の `MODEL_URLS`、`sw.js` の `FILES` に書く

## タブレットで使う

オフラインで動かしたりホーム画面に追加したりするには、**HTTPS で公開する必要がある**（ブラウザの決まり）。いちばん手軽なのは GitHub Pages（無料）。

1. このフォルダを GitHub のリポジトリに置き、Pages を有効にする
2. タブレットでURLを開く
   - iPad（Safari）：共有ボタン →「ホーム画面に追加」
   - Android（Chrome）：メニュー →「ホーム画面に追加」／「アプリをインストール」

## これからの予定（公文式スタイルに向けて）

- [ ] 子供ごとのプロフィール（名前、記録を分ける）
- [ ] 「合格ライン」（例：全問正解かつ○秒以内）を超えたら次のレベルが開く、段階式の進級
- [ ] ひき算、2けたのたし算・ひき算、10の合成・分解（年長向け）
- [ ] 保護者画面（日ごとの記録、苦手な問題）
- [ ] ごほうび（スタンプ帳など）

## 記録が消えるとき（保護者メニュー）

記録はすべてタブレットのブラウザの中（`mathapp.` で始まるキー）に保存される。ブラウザの設定やキッズ用プロフィールによっては消えることがある。

- 「だれが やる？」画面の下の「⚙️ 保護者メニュー」で、保存できるか・最後に保存した日時・使いはじめた日時（記録が消えるとこの日時が新しくなる）を確認できる
- バックアップ：ファイルに保存、またはコードを表示してコピー。もどす：ファイルかコードから（いまの記録は上書き）
- 起動時にブラウザへ「データを消さないで」とお願いしている（`navigator.storage.persist()`。対応していないブラウザもある）
